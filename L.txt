**🔴 Finding: gh and git get different tokens from the proxy**
- **`gh repo view` reached the private org repo**, but **`git push` to the same repo got 403 SSO**.
- So the proxy injects **two different credentials**:
  - For **api.github.com (gh)**, a token that **is** approved for the org's SSO.
  - For **github.com git traffic**, the **Copilot CLI app token**, which **isn't**.
- **Effect:** inside the sandbox, the agent can read repos and open PRs through `gh`, but **can't push**. That's a blocker for agent coding workflows in any SSO org.
- **Possible fix:** the org owner approves the **"GitHub Copilot CLI"** app in **Org settings → Third-party access → OAuth application policy**, and you complete the SSO authorization.
